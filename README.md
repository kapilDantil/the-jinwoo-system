# ⚡ JINWOO SYSTEM — Gamified Productivity Dashboard

> **Turn your daily routine into a quest. Build discipline, complete missions, earn XP, and level up in real life.**

JINWOO SYSTEM is a Solo Leveling-inspired productivity dashboard that transforms everyday tasks and study sessions into an RPG-style progression system. Manage your timetable, create personal quests, earn experience points, and track your growth through levels, ranks, and player statistics.

## ✨ Features

- 🎯 **Quest Management** — Create, complete, undo, and delete tasks.
- 📅 **Weekly Timetable** — View a structured Monday-to-Saturday college schedule.
- 📝 **Timetable Management** — Add custom sessions with a day, time, and XP reward.
- ⚡ **XP & Leveling System** — Earn XP by completing quests and progress through levels.
- 🏆 **Rank Progression** — Advance from E-Rank to S-Rank as you level up.
- 💪 **Player Statistics** — Track Strength, Agility, Intelligence, and Endurance.
- 🎉 **Level-Up Notifications** — Receive system-style notifications and level-up screens.
- 💾 **Local Data Persistence** — Save your progress in the browser using `localStorage`.
- 🚀 **Quick Actions** — Start focus sessions or populate the dashboard with demo quests.
- 📱 **Responsive Interface** — Adapted for desktop, tablet, and mobile screens.
- 🌌 **Dark Sci-Fi UI** — Neon cyan accents, glowing panels, futuristic visuals, and an RPG-inspired interface.

## 🛠️ Built With

- **HTML5** — Page structure and components
- **CSS3** — Styling, responsive layouts, gradients, and glowing effects
- **Vanilla JavaScript** — Quest logic, XP calculations, progression, and UI updates
- **Browser LocalStorage** — Persistent local progress

## 🚀 Getting Started

No installation, framework, database, or build tools are required.

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Open the project folder.
3. Open `timetable.html` in your browser.
4. Create your first quest and start earning XP!

Alternatively, download the HTML file and open it directly in any modern browser.

## 🎮 How It Works

1. Add a quest or create a timetable session.
2. Assign an XP reward to your task.
3. Complete the quest to earn XP.
4. Level up as you accumulate enough experience.
5. Improve your player stats and climb the rank system.
6. Track your productivity and keep progressing.

**Rank progression:** E → D → C → B → A → S

## 💾 Data Storage

Your progress is stored locally in your browser using `localStorage`. This means your quests, XP, levels, and stats can persist between visits in the same browser profile.

**Note:** LocalStorage is device- and browser-specific. Your progress does not automatically synchronize across devices, and clearing browser data may remove your saved progress.
